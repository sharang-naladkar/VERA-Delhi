# Sample Evidence Data Directory

This directory holds sample test artifacts for subsequent testing phases:
- `text/` — Suspicious Telegram/WhatsApp transcript samples
- `images/` — Fake certificates, manipulated trading screenshots
- `audio/` — Fraudulent voice note samples
- `videos/` — Deepfake advisory videos
- `apks/` — Malicious APK samples
- `urls/` — Phishing domain lists
